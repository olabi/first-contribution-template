# References and exploratory work

A place for reading notes and personal experiments before they are ready for the main project. See [the scoped rules](AGENTS.md).

Suggested layout: `references/P01/topic/README.md` and a small text-based experiment script if useful. P01 is a pseudonym, not a real-name mapping or proof of authorship. Create only the folders you need; do not overwrite another member's notes.

Copy this lightweight note when useful:

```markdown
# Topic
Status: exploratory / not team-approved
Question:
Source links and access date:
What I tried:
Environment, source version, and commands (if run):
Observed result or not run:
Limitations and open questions:
Possible next step:
```

Formal issues, completed experiments, and acceptance reviewers are optional at this exploratory stage. A source citation, honest execution status, and clear limits are still important. The folder is tracked and may be shared; it is not private storage just because it is called references.

Before using a result in the final code or research write-up, follow the promotion steps in AGENTS.md. Privacy checks, publication permission, and data/third-party rights remain unchanged. Keep real work in your team's private repository; this public template contains guidance only.
